Theme editor

Change a value to preview it on the whole page in real time. For colors, click the swatch for the system picker, or type / paste a HEX (e.g. #3a54eb — the # is optional). When you like the result, copy the generated CSS and paste it over the :root block in styles.css.

01

Colors

Near-black ink on a warm off-white. One accent (indigo) for emphasis, one green for positive status. Secondary tones are derived from ink, so the palette stays coherent when you change it. Click a swatch to copy its var().

02

One sans-serif family throughout — no mixing weights that fight. Display sizes are tight-tracked and tight-leading; body text stays comfortable. Change the family in the theme editor above.

How to edit

Everything lives in two files.

styles.css

The source of truth: the :root tokens at the top, then every reused class (buttons, badges, cards, forms, rows). Change a token once and it updates the whole site.

this page

Tweak the theme editor, copy the generated :root block, and paste it into styles.css. Copy any component's HTML with the button on each demo.
